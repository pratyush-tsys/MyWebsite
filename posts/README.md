# Add a blog post

Create a new Markdown file in this folder. Use a lowercase, hyphenated filename.

Example: iso-8583-field-55.md

Start with this frontmatter:

---
title: "Understanding ISO 8583 Field 55"
date: "2026-10-18"
description: "Learn how Field 55 carries EMV transaction data."
category: "ISO 8583"
---

# Understanding ISO 8583 Field 55

Write your article using Markdown. Supported metadata: title, date, description, category, and optional slug.

The build script creates blogs/<slug>.html and updates blog.html. Do not edit generated pages directly.
